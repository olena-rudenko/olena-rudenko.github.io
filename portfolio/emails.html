Emails for The Hotel

This project is a set of emails designed for the hotel. The main requirement is responsive layout and main goal is maximizing conversions of hotel.

Description:

Hotel email campaigns has become more important than ever. Especially for new growing hotel system. Today’s hotels should have the digital conversation with guests. That conversation begins well before arrival and it extends through the confirmation process and post-stay. This set designed specifically for hotels's needs.

What was done:

1. Design based on the Email best practices.
2. Responsive layout optimized for mobile.

Mobile optimization:

All emails from this set were optimized for mobile devices and have perfect look in all mail services. The main feature are clear and concise design. It's adheres to the clean with considerable negative space so readers can easily distinguish the content.
